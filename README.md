# kwtSMS for monday.com

Free monday.com marketplace app that sends one-way SMS via the kwtSMS gateway.

## Features (v1)

- 4 integration recipes: item created, status-to-value, any column changed, T-N days before a date
- Account Settings with Connect, templates, logs, notifications, help
- Dashboard Widget with balance, sent, failed, delivery rate
- Item View with SMS history and ad-hoc composer
- Board Menu action "Send SMS to selected items"
